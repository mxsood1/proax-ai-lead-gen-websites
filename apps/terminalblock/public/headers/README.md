# Page header photos

Background photos behind the page headers (Finder, Identify, Types, Guides, How it works), shown under a colour tint.

- They are public-domain photos (US government agency images via Wikimedia Commons), so no credit is required. They were cropped and, for the warehouse shot, blurred so that no agency markings or box labels are readable.
- To swap one, save a landscape photo around 1920 px wide as `header-<page>.webp` here and update its size in `src/data/photos.json`. Only use photos that need no attribution (public domain, CC0) or that Proax has licensed.
